# 크로스링크 (CrossLink)

비스트를 기르는 **테이머**와 덱으로 싸우는 **듀얼리스트**가 한 대륙에 공존하는 2D 크로스오버 RPG.
두 진영은 **각자 자기 규칙 그대로** 싸우며, 서로 다른 규칙끼리도 대결할 수 있다.

> 몬스터 육성 RPG와 카드 듀얼 게임, 두 장르의 규칙을 구현한 오리지널 작품입니다.
> 생물·카드·세계관·그래픽은 모두 이 게임을 위해 새로 만든 것입니다.

## 실행

설치나 빌드가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.

| 조작 | 키보드 | 터치 |
|---|---|---|
| 이동 | 방향키 / WASD | 십자 패드 |
| 대화·조사·확인 | Z / Enter / Space | A |
| 메뉴·취소 | X / Esc | B |

전투는 버튼과 카드를 클릭(탭)해서 진행합니다. 진행 상황은 브라우저에 자동 저장됩니다.

타이틀의 **자유 대전**에서 네 가지 대진(비스트 vs 비스트 / 덱 vs 덱 / 비스트 vs 덱 / 덱 vs 비스트)을 바로 체험할 수 있습니다.

## 게임 내용

- **월드**: 새싹 마을 → 풀잎길 → 카드리아 시 → 속삭임 숲 → 리파 마을 → 물결 해안 → 잿빛 동굴 → 크로스 시티 (실내 포함 맵 25개, NPC 64명)
- **스토리**: 엠블럼 4개(테이머 도장 2 + 듀얼 홀 2)를 모아 크로스 리그에 도전. 라이벌 레온(테이머)·미라(듀얼리스트), 두 세계를 다시 갈라놓으려는 분리단.
- **비스트 33종**: 포획, 레벨업, 기술 습득, 진화, 9속성 상성, 상태이상
- **카드 53종**: 몬스터(일반/효과/제물 소환), 마법(일반/장착/지속), 함정, 덱 편집(20~30장), 카드 팩
- 상점, 링커 센터(회복·보관함), 도감, 전설의 비스트, 엔딩 후 콘텐츠

NPC에게 승부를 걸면 **비스트로 싸울지 덱으로 싸울지** 고릅니다. 상대가 테이머든 듀얼리스트든 상관없습니다.

## 세 가지 전투 규칙

### 비스트 룰 (테이머 vs 테이머)
양쪽이 동시에 행동을 고르고 스피드 순으로 움직입니다. 속성 상성, 자속 보정, 급소, 능력 랭크, 독·화상·마비·수면, 교체, 도구, 포획, 도주.

### 카드 룰 (듀얼리스트 vs 듀얼리스트)
번갈아 턴을 진행합니다. 턴당 일반 소환 1회, ★5~6은 제물 1장·★7 이상은 2장, 공격/수비 표시와 뒷면 세트, 리버스 효과, 장착·지속 마법, 상대 행동에 반응하는 함정. LP 0 또는 덱 소진 시 패배.

### 크로스 룰 (테이머 vs 듀얼리스트)
핵심 원칙: **자기 쪽 자원은 자기 규칙을 따른다.** 비스트는 HP·속성·상태이상을 가진 채로, 카드 몬스터는 HP 없이 ATK/DEF 비교로 파괴되는 채로 싸웁니다.

| 상황 | 처리 |
|---|---|
| 승패 | 테이머는 비스트 전멸 시, 듀얼리스트는 LP 0(또는 덱 소진) 시 패배 |
| 턴 | 번갈아 진행. 듀얼리스트는 한 턴에 소환·마법·공격을 모두, 테이머는 행동 1회 |
| 비스트 → 몬스터 | 기술이 **스트라이크**(공격 × K × 위력/60 × 자속 1.2 × 상성)로 환산. ATK(수비 표시면 DEF) 이상이면 파괴, 공격 표시였다면 초과분이 LP 데미지. 못 부수면 **충격**으로 ATK/DEF를 스트라이크의 절반만큼 깎음 |
| 비스트 → 빈 필드 | 스트라이크가 그대로 LP 데미지 |
| 몬스터 → 비스트 | 비스트 룰의 데미지 공식으로 HP를 깎음 (몬스터 속성 vs 비스트 속성 상성 적용) |
| 스피드 | **쾌속**: 몬스터를 격파했을 때 스피드 환산치 ≥ 그 몬스터 레벨 × 400이면 1회 추가 행동 |
| 카드 효과 → 비스트 | 「파괴」는 최대 HP의 35% 피해, 효과 데미지는 선두 비스트가 대신 받음, ATK 증감은 능력 랭크 변화, 「패로 되돌린다」는 강제 교체 |
| 상태이상 | 양쪽에 공통. 몬스터는 독(매 턴 ATK/DEF −200), 화상(ATK −30%), 마비·수면(공격 불가) |
| 함정 | 비스트의 공격 기술과 교체에도 반응 |

**링크 레벨**: 카드의 수치는 절대값이고 비스트의 능력치는 레벨에 따라 커지므로, 환산 계수 K를 상대의 격(레벨)에 맞춰 정합니다 (`K = 2300 / Lv^1.43`). 그래서 비스트의 레벨업과 덱의 카드 품질이 각각 의미 있는 성장이 됩니다.

상수는 AI끼리의 대전 시뮬레이션으로 조정했습니다. 동급 대진에서 테이머 : 듀얼리스트 승률은 초반 59:41, 중반 43:57, 후반 51:49 수준입니다.

## 구조

```
index.html            진입점 (스크립트 태그만, 빌드 불필요)
css/style.css
js/core.js            네임스페이스, 결정론적 RNG, 유틸
js/data/              beasts.js(속성·기술·비스트·도구)  cards.js(카드·덱·팩)  world.js(맵·NPC·스토리)
js/engine/            beast.js(개체·성장)  battle.js(전투 엔진)  ai.js(AI)      ← DOM 의존 없음
js/ui/                sprites.js(절차적 픽셀 아트)  main.js  overworld.js  battleui.js  menus.js
tools/                sim.js(밸런스·퍼징·결정론 검증)  checkworld.js(월드 검증)  build.js(단일 파일 빌드)
```

모든 그래픽은 코드로 그립니다. 외부 이미지·라이브러리가 없습니다.

```bash
npm test
```

```bash
npm run build
```

`npm test`는 월드 데이터 검증(좌표, 워프, 도달 가능성)과 전투 시뮬레이션(승률, 무작위 행동 퍼징, 리플레이 일치)을 돌립니다. `npm run build`는 `dist/crosslink.html` 단일 파일을 만듭니다.

## 멀티플레이 확장

전투 엔진은 처음부터 네트워크 대전을 염두에 두고 설계했습니다.

- **커맨드/이벤트 구조**: `battle.request(side)`가 그 진영이 내릴 결정을 알려 주고, `battle.submit(side, action)`이 이벤트 목록을 돌려줍니다. 사람·AI·원격 플레이어가 모두 같은 경로를 씁니다. 불법 행동은 상태를 바꾸지 않고 거부됩니다.
- **결정론**: 상태는 순수 JSON이고 난수 시드도 그 안에 있습니다. `battle.init`(초기 조건)과 `battle.log`(행동 기록)만 있으면 `Battle.replay(init, log)`로 같은 전투가 재현됩니다. `npm test`가 이를 검증합니다.
- **비공개 정보**: `Battle.viewFor(state, side)`가 상대의 패·덱·뒷면 카드를 가립니다. UI는 이미 이 뷰만으로 그려집니다.
- **동시 선택**: 비스트 룰은 양쪽 선택이 모일 때까지 기다렸다가 해결하므로 네트워크 지연에 그대로 대응합니다.
- **엔진/UI 분리**: `js/engine/`은 DOM을 쓰지 않아 Node 서버에서 그대로 돌아갑니다.

서버 권위 방식이라면 서버가 `Battle`을 돌리며 각 클라이언트에 `viewFor` 결과와 이벤트를 보내면 되고, P2P 락스텝이라면 시드와 행동만 교환하면 됩니다. `js/ui/battleui.js`의 진행 루프에서 `AI.decide` 자리에 원격 입력을 끼우는 것이 연결 지점입니다.
