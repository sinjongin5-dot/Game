# ARENA — 모래와 송곳니

고대 콜로세움의 모래 경기장에서 검투사가 되어 거대한 숫사자와 일대일로 맞서는 **3D 3인칭 소울라이크 보스 결투**.
TypeScript + Vite + Three.js, 충돌/캐릭터 이동은 Rapier, 모델·텍스처·사운드는 전부 이 저장소의 스크립트로 생성합니다.

타이틀 → 입장 연출 → 결투(2페이즈) → 사망/재도전 → 승리 화면까지 하나로 연결되어 있습니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 http://localhost:5173  (F3: 진단 오버레이/히트박스)
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과 미리보기 http://localhost:4173
npm test           # 단위/통합 테스트 (vitest)
npm run typecheck  # tsc --noEmit
```

에셋 재생성(이미 커밋되어 있으므로 보통 필요 없음):

```bash
npx tsx tools/gen-lion.ts        # public/assets/models/lion.glb
npx tsx tools/gen-gladiator.ts   # public/assets/models/gladiator.glb
npx tsx tools/gen-textures.ts    # public/assets/textures/shield_face.png
python3 tools/gen-audio.py       # 효과음/대기 음악 public/assets/audio/*.ogg  (numpy, scipy, ffmpeg 필요)
python3 tools/gen-music.py       # 보스전 음악 2곡 (music_battle, music_phase2)
npx tsx tools/build-fonts.ts     # UI 글자 슬라이스만 골라 public/assets/fonts 에 복사
```

브라우저 종단 간 테스트(헤드리스 Chromium + SwiftShader, 개발 서버 실행 필요):

```bash
npm run dev &
node tools/e2e.mjs ui|input|fight|all      # 결과: captures/e2e-report.json, captures/e2e_*.png
```

## 게임 규칙

- **HP 100 / 스태미나 100.** 약공격 18, 강공격 32, 회피 25. 스태미나가 부족하면 행동이 실행되지 않습니다. 소비 후 0.7초 뒤 회복이 시작되고, 방패를 든 동안엔 회복이 25% 로 느려집니다. 달리기는 계속 소모합니다.
- **회피**: 전체 0.72초, 무적은 시작 후 0.10~0.34초. 구간 밖에서는 피해를 입습니다. 입력 버퍼 0.15초.
- **방패**: 몸 앞 ±78° 안의 공격만 막습니다. 막을 때마다 스태미나가 줄고(앞발 26 / 물기 30 / 도약 48 / 돌진 55), 모자라면 가드 브레이크(1.1초 경직 + 피해 일부). 방패를 올린 직후 0.16초 안에 막으면(퍼펙트) 소모가 절반입니다.
- **회복**: 시작 즉시 횟수를 소비하고, 0.72초에 HP +45. 맞으면 중단되고 횟수는 돌아오지 않습니다.
- **사자(HP 900)**: 아래 *보스 패턴* 표의 10가지 기술. 체력 55% 이하에서 **한 번만** 2페이즈(포효, 무적 연출 2.3초)로 전환하며 *앞발 후 지연 물기*, *도약 후 추가 앞발* 연계가 붙고 선회/접근이 빨라지며 눈이 붉게 빛나고 몸에서 불씨가 피어오릅니다. 돌진 중 벽/기둥에 부딪히면 1.9초 기절합니다. 강공격은 경직을 크게 쌓아 사자를 비틀거리게 하고(이후 7초간 경직 누적 30%), 비틀거리는 동안 피해가 1.35배입니다.

### 보스 패턴 (전조 시간은 `src/combat/attackData.ts` 의 windup)

| 패턴 | 전조 | 내용 | 대처 |
|---|---|---|---|
| 앞발 휘두르기 | 0.78s | 사정거리 안에서 한 번 베기 | 회피 / 방패 |
| 물기 | 0.62s | 가까이서 문다 | 회피 / 방패 |
| 도약 덮치기 | 0.95s | 웅크렸다가 3~8m 를 뛰어 덮침 | 도약 직전에 회피 |
| 돌진 | 1.15s | 7m 이상에서 달려옴, 벽·기둥에 박으면 기절 | 옆으로 피하며 벽으로 유도 |
| 측후방 견제 | 0.85s | 등 뒤에 오래 서 있으면 휘두름 | 정면으로 돌아서기 |
| **연타 할퀴기** | 0.70s | 오른발→왼발→오른발 3연타, 둘째·셋째 타는 박자가 빠름 | 방패로 3번 막거나 크게 물러남 |
| **돌진 물기** | 0.78s | 중거리에서 몸을 낮췄다가 순식간에 파고들어 묾 | 달려드는 순간 옆으로 회피 |
| **뒷걸음 도약** | 0.70s+ | 뒤로 크게 물러난 뒤 곧바로 도약 덮치기로 이어짐 | 물러난 뒤의 웅크림을 읽고 회피 |
| **충격파 강타** | 1.00s | 뒷다리로 일어서 땅을 내리찍으면 바닥을 따라 링이 8m 까지 퍼짐 | 링이 닿는 순간 회피, 방패, 또는 멀리 있기 |
| **회전 꼬리치기** | 0.85s | 제자리에서 한 바퀴 돌며 주변을 전부 쓸어냄 (붙어 있거나 등 뒤에 있으면 벌) | 전조 때 멀리 회피 |
| 2페이즈 연계 | 0.4s | 앞발→지연 물기, 도약→추가 앞발 | 첫 타 뒤에도 방심하지 않기 |

- **페인트(전조 정지)**: 앞발/물기/돌진 물기/연타는 가끔 전조 동작에서 0.3~0.6초 멈췄다가 들어옵니다(1페이즈 22%, 2페이즈 45%). 박자를 외워 구르면 빗나가고, 정지가 풀리는 순간을 보고 움직여야 합니다.
- 큰 기술(충격파·회전·돌진 물기·연타)은 끝난 뒤 빈틈이 0.3~0.55초 더 깁니다 — 반격 기회입니다.
- 같은 계열(할퀴기/물기)은 연속해서 잘 나오지 않도록 가중치가 조정됩니다.
- 모든 공격은 *준비 → 유효 판정 → 후딜* 타임라인으로 판정하며, 같은 공격 인스턴스는 한 번만 피해를 줍니다. 애니메이션은 판정과 같은 데이터(검/발톱/머리 궤적)를 IK 로 풀어 그립니다.

## 조작감 / 타격감 (v1.1)

- **공격 속도**: 약공격 첫 타 유효 시점이 0.22초 → 약 0.17초, 전체 길이는 22% 단축, 돌진 거리 +30~45%. 판정과 애니메이션 키를 같은 비율로 압축하므로 동기화는 유지됩니다(테스트).
- **자동 조준**: 락온 중이거나, 사자가 6.5m 안에 있고 입력 방향이 사자 쪽(±80°)이면 공격 시작 순간 사자를 향해 몸을 돌립니다. 입력 방향이 반대면 그 방향으로 공격합니다.
- **후딜 취소**: 유효 구간이 끝난 뒤 이동 입력을 하면 바로 걸어 나갑니다. 회피 취소는 기존대로.
- **이동**: 가속 22→36, 걷기 3.0→3.2m/s, 회전 12→15rad/s.
- **발놀림**: 공격 중 방패 쪽(왼발)이 내딛고 오른발이 끌려오며 착지 시 먼지/발소리가 납니다(이전엔 보행 사이클이 그대로 돌았음).
- **히트스톱 중 입력 보존**: 타격 정지(0.05~0.3초) 동안 누른 공격/회피/회복 입력을 버퍼에 쌓아 입력이 씹히지 않습니다.
- **타격 연출**: 히트스톱(머리 가격/경직/처치 시 더 김) · 카메라 킥(타격 방향) · FOV 펀치와 롤 · 짧은 슬로모션(강타 0.1초, 경직 0.2초, 처치 1.1초, 완벽 방어 0.2초, 완벽 회피 0.14초) · 피격 시 캐릭터 전체 플래시(사자=밝게, 검투사=붉게) · 번쩍임 스프라이트 + 스윙 방향 베기 줄기 · 털 조각/불꽃 · 전체 화면 번쩍임(패링=청백, 가드 브레이크/사자 포효=적색, 처치=백색). 슬로모션/번쩍임/카메라 킥은 설정의 *카메라 흔들림* 을 0 으로 하면 모두 꺼집니다.
- **사자 공격 이펙트**: 앞발 궤적(발톱 잔상) · 물기 순간 섬광 · 충격파 링 + 링을 따라 퍼지는 먼지 벽 + 바닥 균열 · 회전 꼬리치기의 모래 소용돌이 · 돌진 물기/돌진의 먼지 꼬리 · 뒷걸음 도약의 이륙/착지 먼지 · 전조 때 번뜩이는 눈빛 · 2페이즈 상시 붉은 눈과 불씨 · 2페이즈 전환 시 적색 충격파.
- **카메라**: 사자에게 붙을수록 카메라를 오른쪽 어깨 너머로 더 빼서 준비 동작이 플레이어 몸에 가려지지 않게 했습니다.

## 음악

`tools/gen-music.py` 가 보스전 곡 2개를 합성합니다(이음매 없는 루프). 1페이즈(92BPM, 약 42초): 낮은 드론 + E♭ 반음 충돌, 심장 박동 같은 큰북, 4마디마다 부풀어 오르는 떨리는 현 클러스터, 합창 패드, 금관 스탭, 금속 틱, 상승 라이저. 2페이즈(128BPM, 30초): 16분 큰북 오스티나토 + 8분 베이스 펄스 + 더 높고 거친 현/합창.
제작 중에는 소리를 사람이 직접 들어 보지 못했고, 스펙트럼 분포·루프 이음매 연속성·클리핑 여부만 수치로 확인했습니다(아래 제한 사항).

리타게팅 방법과 라이선스 주의는 `tools/bake-anims.ts` 상단 주석과 `ASSET_LICENSES.md` 를 보세요. 원본 FBX 는 저장소에 없습니다.

## 이동 떨림 수정 (v1.2)

걸을 때 캐릭터가 덜덜 떨리던 **원인은 물리 설정**이었습니다. 캐릭터 충돌 캡슐의 바닥이 바닥 면에 정확히 닿아 있어서 Rapier 캐릭터 컨트롤러가 수평 이동을 계산할 때마다 바닥 접촉을 옆으로 미는 힘/감속으로 해석했고, 직선으로 걸어도 속도가 3.2→1.8m/s 로 떨어지고 좌우로 ±1.6m/s 튀었습니다(0.15~0.3초마다). 충돌체를 8cm 띄워 해결했고, 같은 조건에서 걷기·옆걷기 속도 표준편차가 0.9→0.000m/s 가 됨을 확인했습니다(테스트 로그 기준). 그 외 카메라가 시뮬레이션의 계단식(60Hz) 위치 대신 캐릭터 메시와 같은 보간 위치를 따라가도록 바꿨습니다.

### 난이도 관련 실측 (규칙 기반 봇 `tests/bot.ts` — 사람이 아닙니다)

| 봇 숙련도 | 결과 | 평균 전투 시간 |
|---|---|---|
| 0.97 (거의 항상 읽고 회피/방어) | **18/40 승 (45%)** | 73초 (42~103초) |
| 0.4 | 0/20 승 | 21초 |
| 0 (회피/방어 없음) | 0/20 승 | 17초 |

- 이동 떨림(물리 버그)을 고치기 전에는 같은 봇이 15%(6/40)만 이겼습니다 — 걸을 때 속도가 튀어서 사자의 공격을 피하는 것도 어려웠다는 뜻입니다. 지금 수치는 **떨림이 없는 물리 기준**입니다.
- 즉 "맞으면서 때리기만" 해서는 이길 수 없고, 읽고 대응하면 이길 수 있는 구조임을 확인했습니다. 사람 플레이어의 클리어율은 **측정하지 못했습니다.** 신규 패턴을 넣으며 피해량/쿨다운/연타 박자를 조정했습니다(연타 타 사이 0.35~0.37초, 충격파 방어 비용 50→40, 새 기술 쿨다운 7.5~11초, 일부 기존 기술 피해 −2~−6). 완벽에 가까운 봇이 45% 이기므로 사람에게는 더 어려울 것으로 보이지만 **사람 데이터는 없습니다.** 너무 쉽거나 어렵게 느껴지면 `src/combat/attackData.ts` 의 damage/cooldown 으로 조정하세요.
- 개발 중 발견·수정한 문제: (1) 플레이어가 사자에 바짝(약 1.1m 이내) 붙으면 사자가 공격 후보를 못 찾아 맞고만 있던 사각지대(앞발 최소 사거리 1.1m → 0.5m). (2) 극단적인 상황에서 플레이어 중심이 경기장 타원을 3cm 넘어선 것을 봇 시뮬레이션에서 발견 → 경기장 이탈 방지 안전장치 추가. (3) 브라우저에서는 프레임 루프가 섞여 같은 시드라도 봇 결과가 달라질 수 있어, 승리 캡처/e2e 는 이길 때까지 시드를 바꿔 가며 시도합니다(모두 정상 전투).

## 제한 사항 / 미검증 항목

- **그래픽 수준 ("언리얼 엔진 5.x급" 요청에 대해)**: 언리얼 엔진 5 의 Nanite(가상 지오메트리)·Lumen(실시간 GI)·스캔 에셋·MetaHuman 은 WebGL 브라우저 게임과 코드 생성 에셋으로는 **재현할 수 없습니다.** 대신 WebGL2 에서 가능한 범위에서 최대한 끌어올렸습니다: HDR(HalfFloat) 렌더 타깃 + MSAA, 화면공간 AO(깊이 기반, 하프 해상도 + 양방향 블러), 블룸 체인, 태양 갓레이, 깊이 기반 피사계 심도, 높이 안개 + 태양 산란, ACES 톤매핑/그레이딩/비네트/필름 그레인/색수차, 절차적 하늘(레일리·미 산란, HDR 태양, fbm 구름) + 반구광·바운스광·IBL, 4096 PCF 그림자, MeshPhysicalMaterial(클리어코트/시튼) + 피부 SSS 근사 + 털 투과/림, 해상도 1.4배로 재생성한 사자·검투사 메쉬, 공중 먼지 입자. 결과는 "2020년대 초반 WebGL 데모" 수준이며 UE5 와는 격차가 큽니다. 품질 단계는 낮음/보통/높음/울트라이고, 낮음은 후처리 없이 직접 렌더링합니다. 적응형 해상도는 실 GPU 에서만 동작하며(자동화 브라우저에서는 꺼짐) **실제 GPU 에서 검증하지 못했습니다.**
- **성능**: 실제 GPU 에서의 FPS 는 **측정하지 못했습니다.** 이 환경에는 GPU 가 없어 SwiftShader(소프트웨어 렌더)로만 돌렸고 약 2fps 수준이라 e2e 에서는 시뮬레이션을 `simAdvance` 로 가속했습니다. Low/Medium/High/Ultra 프리셋(털 셸 수, 군중 밀도, 그림자 해상도, 렌더 해상도)은 구현되어 있으나 프리셋별 FPS 수치는 없습니다.
- **오디오**: 소리가 실제로 어떻게 들리는지는 사람이 듣고 확인하지 못했습니다(헤드리스). 이벤트 → 사운드 연결, 볼륨 저장, 오디오 소스 누적 없음, 그리고 보스전 음악의 스펙트럼 분포·루프 이음매·클리핑 여부만 자동/수치로 검증했습니다. "긴장감 있게 들리는가"는 주관적 판단이라 검증하지 못했습니다. 사운드는 numpy/scipy 합성이라 실제 녹음/연주보다 질감이 단순합니다.
- **조작감/타격감**: 코드·수치·정지 화면 캡처로만 확인했습니다. 실제 손맛(입력 지연, 발놀림이 자연스러운지, 슬로모/카메라 킥의 강도)은 GPU 가 있는 환경에서 직접 플레이해 보지 못했습니다. 너무 강하면 설정의 *카메라 흔들림* 을 낮추면 슬로모/번쩍임/카메라 킥이 함께 약해지거나 꺼집니다.
- **모델 품질**: 라이선스가 확실한 외부 리깅 에셋을 받을 수 없어 사자와 검투사를 SDF 로 직접 모델링했습니다. 사자 얼굴·털, 인체 비례·손가락은 상용 AAA 에셋 수준이 아닙니다. 털은 셸 셰이더 + 갈기 카드 근사입니다.
- **모션 캡처**: Mixamo 캐릭터와 이 프로젝트 검투사는 비율이 달라(팔/다리 길이, 갑옷·방패 크기) 손·발 위치가 원본과 다소 다르고, 검을 쥐는 각도는 준비 자세에서 칼날이 앞쪽을 향하도록 가정해 보정했습니다(공격 중 칼날 방향이 원본과 다를 수 있음). 클립이 있는 5개 동작 외(약공격 3연계, 회피, 회복, 걷기/달리기, 피격)는 여전히 절차적 애니메이션이라 두 스타일이 섞입니다. 도약 내려찍기는 발이 지면에 고정되지 않고(IK 미적용) 착지 시 약간 미끄러질 수 있습니다. 눈으로 확인한 것은 정지 화면 캡처뿐입니다.
- **입력**: 키보드+마우스만 검증했습니다. 게임패드/터치는 지원하지 않습니다. 포인터 잠금이 거부되는 환경에서는 폴백(클릭 드래그 시점)으로 동작합니다.
- **브라우저**: 헤드리스 Chromium 에서만 확인했습니다. Firefox/Safari 는 미검증입니다.
- **번들 크기**: 코드 분할을 하지 않아 첫 로딩에 약 1.7MB(gzip) + 에셋 6.2MB 를 받습니다.
- **밸런스**: 위 봇 수치 외에 사람 플레이테스트 데이터는 없습니다. 수치는 `src/simulation/tuning.ts`, `src/combat/attackData.ts` 에 모여 있어 조정이 쉽습니다.
- 배포는 하지 않았습니다(로컬 `npm run dev` / `npm run preview` 로만 실행).
