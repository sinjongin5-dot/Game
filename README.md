# GEARHEART (stage 03) — 대규모 패치

플레이용 파일은 `gearheart_stage_03_1.html` 하나입니다(브라우저에서 바로 열면 됩니다).
이 패치는 기존 HTML 위에 아래 6가지 문제를 고친 버전입니다. 원본은 첫 커밋(`Add original GEARHEART stage 03 build as baseline`)에 그대로 있습니다.

## 고친 것

| # | 문제 | 패치 내용 |
|---|------|-----------|
| 1 | 튜토리얼이 끝났는데 튜토리얼 창이 계속 뜸 | 훈련장 완료/이탈 상태를 저장(`save.tutDone`/`tutSeen`). 완료 후엔 카드·칩이 다시 뜨지 않고, 코스 밖에서는 칩이 사라지며, 완료한 스테이션 카드는 도장 후 사라짐. 2장 타이탄 안내도 1회만. |
| 2 | 중간보스 스토리가 약하고 너무 자주 나옴 | 보스 홀을 **1장 끝(브람) → 4장 끝(벨로)** 로 이동(3챕터 간격, 이후 7장 거버너·8장 윈더). 브람/벨로 전투 패턴을 전부 새로 작성(아래), 단계 전환마다 짧은 대화, 길목의 **기록 단말 8개**(읽는 속도는 플레이어가 결정, 정비대 `기록 보관함`에서 다시 읽기), 읽은 기록에 반응하는 정비소 주민 대사. |
| 3 | 맵/에셋 재사용이 심함 | 챕터별 **배경 스카이라인**(시계탑, 파이프 오르간, 기어탑, 프레스 공장, 플라이휠, 테슬라 단지, 용광로, 심장), **타일 재질**, 챕터별로 직접 그린 **소품 40여 종**(애니메이션/조명 포함), 챕터별 **공기 입자·BGM 색깔**, 연결 통로·기술실·이벤트실의 **챕터별 변형 레이아웃**(물리 도달성 검증 통과분만). |
| 4 | 공격이 단순함 | 충전 베기(X 길게) / 회전 베기(↑) / 급강하(공중 ↓), 돌진 베기(대시 중 X), 증기탄(A 톡, 소울 22), 타이탄 피스톤 강타·어퍼컷. |
| 5 | 적 패턴이 단조로움 | 기존 6종이 챕터별 변종 행동(급강하·저격 드론, 연사·조준·확산 터릿, 돌진 용접공, 연속·충격 호퍼, 일제 박격포)을 갖고, 신규 5종(방패병, 폭탄 드론, 회전톱, 수리 드론, 잠복 상자) 추가. |
| 6 | 맵별 차이가 없음 | 위 3번 + 5번이 챕터마다 다른 조합으로 배치됨. |

### 중간보스 패턴
* **브람(점호)** — 박자 종소리(타종 횟수만큼 양쪽에서 충격파), 긴 막대 휩쓸기→내려찍기 콤보, 시계바늘 두 개가 도는 바늘 공격(끝나면 태엽이 풀려 노출), 낙하하는 종, 벽에 부딪히는 돌진(노출). 3단계(66%/33%).
* **벨로(징수)** — 높이가 다른 청구서 3발(낮음=점프, 높음=점프 금지), 플레이어를 따라오는 증기 사냥, 3연 박격, 굴러오는 보일러(벽에 박히면 과열 노출), 흡인 후 압류 충격, 집게가 막는 퍼지 창구 + 3단계 증기 폭풍.

## 개발 메모
소스는 `src/*.js` 에 있고 `python3 tools/build.py` 가 HTML 안의 `/*@NAME_BEGIN*/ … /*@NAME_END*/` 구간에 주입합니다.

| 파일 | 내용 |
|------|------|
| `src/boss.js` | 브람·벨로·신규 보스 위험물·보스 흐름 |
| `src/notes.js` | 기록 단말, 읽기 UI, 기록 보관함, 주민 반응 대사 |
| `src/combat.js` | 신규 공격(충전/회전/급강하/돌진/증기탄/타이탄 강타) |
| `src/enemies.js` | 적 변종, 신규 적 5종, 챕터별 배치 |
| `src/bg.js`, `src/tiles.js`, `src/props.js`, `src/audio.js` | 챕터별 배경·타일·소품·사운드 |
| `src/annex.js` + `src/annex_pre.json` | 연결 통로/기술실/이벤트실 변형(`node tools/bake_annex.js` 로 다시 굽기) |
